## Passos para Instalação
1. Instale o Python 3.12.0 e o MySql Server
2. Abra seu terminal de preferência entre no diretorio onde o jogo está instalado e rode `python -m venv venv` se seu sistema operacional é Linux ou Mac, para Windows `python -m venv .venv`
3. Inicie sua venv com `source venv/bin/activate` ou `source .venv/Scripts/activate`
4. Instale as dependencias do projeto com o comando `pip install -r requirements.txt`
5. Instale o Banco de Dados utilizando o arquivo dump
6. Configure seu ambiente criando um arquivo .env, utilizando o modelo .env.example
